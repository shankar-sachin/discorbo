## 🗄️ Data Persistence

### Automatic Data Management

All user data is automatically saved to JSON files:

| File | Purpose | Schema |
|------|---------|--------|
| `trivia-scores.json` | Trivia stats | User scores, accuracy |
| `quests.json` | Quest progress | XP, completed quests |
| `battle-stats.json` | Battle records | Wins, losses, streaks |
| `loot.json` | Inventories | Items, rarity stats |
| `quotes.json` | Server quotes | Per-guild storage |
| `bossraid.json` | Boss battles | Active bosses, participants |
| `daily-rewards.json` | Daily system | Coins, streaks |
| `reminders.json` | Reminders | User reminders |
| `afk-users.json` | AFK status | Reasons, timestamps |
| `command-usage.json` | Analytics | Command tracking |

### GDPR Compliance

- Full data deletion via `/clear-my-data`
- Removes user data from all 10 data files
- Atomic writes prevent data corruption
- Automatic backups on file modification

## 🔧 Technical Specifications

### Dependencies

```json
{
  "discord.js": "^14.14.1",
  "dotenv": "^16.4.5",
  "axios": "^1.6.7",
  "mathjs": "^12.3.0"
}
```

### System Requirements

- **Node.js:** v16.9.0 or higher
- **Discord.js:** v14.x
- **Memory:** ~50MB base + data storage
- **Platform:** Cross-platform (Windows, Linux, macOS)

### Architecture

- **Modular Command System:** Dynamic loading from `/commands` directory
- **Event-Driven:** 3 core event handlers (ready, interactionCreate, messageCreate)
- **Utility Modules:** 6 shared utilities (logger, embedBuilder, errorHandler, etc.)
- **Data Layer:** JSON-based persistence with atomic writes

### Performance Features

- Command cooldown system (3-30s based on command)
- Efficient caching for API responses
- Background reminder checker (30-second intervals)
- Optimized embed generation
- Rate limit awareness

## 🚀 Getting Started

### Quick Setup

1. **Prerequisites**
   ```bash
   node --version  # Check Node.js v16.9.0+
   ```

2. **Installation**
   ```bash
   cd Discorbo
   npm install
   ```

3. **Configuration**
   ```bash
   cp .env.example .env
   # Edit .env with your bot token and IDs
   ```

4. **Deploy Commands**
   ```bash
   npm run deploy
   ```

5. **Start Bot**
   ```bash
   npm start
   ```

### First Steps for Users

1. `/help` - View all available commands
2. `/ping` - Test bot responsiveness
3. `/vibecheck` - Check your daily vibe
4. `/daily claim` - Get your first coins
5. `/quest get` - Start your first quest

## 🎯 Recommended Server Setup

### Permissions

Minimum required permissions:
- Send Messages
- Embed Links
- Add Reactions
- Read Message History
- Use Slash Commands

Recommended additional permissions:
- Manage Messages (for quote removal)
- Read Message History (for AFK system)

### Channel Ideas

Create dedicated channels for maximum engagement:
- `#bot-commands` - General bot usage
- `#boss-raids` - Boss battle alerts
- `#leaderboards` - Pin leaderboard updates
- `#quotes` - Highlight best quotes

### Admin Configuration

1. Enable required Discord intents:
   - Server Members Intent
   - Message Content Intent

2. Set up `GUILD_ID` in `.env` for faster command updates during development

3. Configure admin-only features:
   - Boss raid spawning (`/bossraid spawn`)
   - Quote removal (`/quote remove`)
