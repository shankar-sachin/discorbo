## 🌟 Overview

Discorbo v2.0.0 is a major version upgrade that nearly doubles the bot's capabilities — from ~65 commands to **105+ commands**. This release delivers a complete visual overhaul of all games, introduces 3 brand-new systems (Music, Leveling, and Welcome), adds new game modes, and expands commands across every category. If v1.0.0 was the foundation, v2.0.0 is the transformation.

## ✨ Major Features

### 🎵 Music System (10 Commands)

Full-featured music playback for voice channels:

- `/music play <query>` - Play a song or add to queue
- `/music pause` - Pause the current track
- `/music resume` - Resume playback
- `/music skip` - Skip to the next track in queue
- `/music stop` - Stop playback and clear the queue
- `/music queue` - View the current song queue
- `/music nowplaying` - Display the currently playing track
- `/music volume <level>` - Adjust playback volume (1–100)
- `/music shuffle` - Shuffle the current queue
- `/music loop` - Toggle loop mode (off / track / queue)

**Highlights:**
- Queue management with shuffle and loop modes
- Volume control per server
- Now-playing display with progress indicator
- Graceful disconnect on empty channel

### ⭐ Leveling/XP System (8 Commands)

Reward active members with experience and level-based roles:

- `/level view [user]` - View your level, XP, and progress bar
- `/level leaderboard` - Server XP leaderboard
- `/level rewards` - View available level-up role rewards
- `/level set-rewards <level> <role>` - Assign a role reward for a level (Admin)
- `/level set-channel <channel>` - Set the level-up announcement channel (Admin)
- `/level toggle` - Enable or disable the leveling system (Admin)
- `/level reset [user]` - Reset XP for a user or the entire server (Admin)
- `/level set-multiplier <value>` - Set XP multiplier for events (Admin)

**Highlights:**
- XP gained per message with cooldown to prevent spam
- Configurable level-up announcement channel
- Automatic role rewards at milestone levels
- XP multiplier for special events
- Per-server leaderboards

### 👋 Welcome/Leave System (6 Commands)

Greet new members and acknowledge departures:

- `/welcome setup <channel> <message>` - Configure the welcome channel and message
- `/welcome set-leave <channel> <message>` - Configure the leave channel and message
- `/welcome set-role <role>` - Set auto-role assigned on member join
- `/welcome toggle` - Enable or disable the welcome system (Admin)
- `/welcome test` - Preview welcome and leave messages
- `/welcome set-image <url>` - Set a custom welcome banner image

**Highlights:**
- Placeholder support: `{user}`, `{server}`, `{memberCount}`, `{username}`
- Auto-role assignment on join
- Custom banner images for welcome embeds
- Separate channels for welcome and leave messages
- Test command to preview without a real join event

### Connection Handling
- Automatic reconnection with exponential backoff

- Built-in migration framework for v1 → v2 data format changes
- Economy data consolidation (daily-rewards merged into unified economy store)
- Run with `npm run migrate` to upgrade v1 data files

### Help Command
- Updated to display all 10 categories with command counts
- New category pages: Music, Leveling, Welcome
- Paginated navigation for large category listings

## ⚠️ Breaking Changes

### Visual Changes
- **2048** no longer uses QuickChart API — the board is now rendered with Unicode box-drawing characters and emoji tiles. Functionality is identical; only the visual output has changed.
- **Card games** (Blackjack, Poker, War) no longer display card images. All cards are now rendered as compact Unicode glyphs (e.g., `[A♠]`).

### Command Reorganization
- `/fun` subcommands have been reorganized into **creative**, **social**, and **party** subgroups. Existing fun commands retain their names but are now nested under these groups.

### Data Format Changes
- Economy data has been consolidated from multiple files into a unified format. A migration script is provided (`npm run migrate`) for v1 → v2 upgrades.
- Users who skip migration will start with fresh economy data.

### New Required Intents
- `GuildMembers` — Required for welcome system auto-role and member tracking
- `GuildVoiceStates` — Required for music system voice channel management

These must be enabled in both the Discord Developer Portal and your bot's intent configuration.

## 🚀 Upgrade Guide

### Upgrading from v1.0.0

1. **Pull the latest code**
   ```bash
   git pull origin main
   ```

2. **Install new dependencies**
   ```bash
   go mod tidy
   ```

3. **Run data migration**
   ```bash
   npm run migrate
   ```

4. **Enable new intents** in the [Discord Developer Portal](https://discord.com/developers/applications):
   - Server Members Intent ✅
   - Message Content Intent ✅
   - (Both may already be enabled from v1.0.0)

5. **Install FFmpeg** (required for music):
   - Windows: `choco install ffmpeg` or download from https://ffmpeg.org
   - Linux: `sudo apt install ffmpeg`
   - macOS: `brew install ffmpeg`

6. **Deploy commands and start**
   ```bash
   npm run deploy
   npm start
   ```

### Fresh Install

Follow the standard setup in `SETUP_INSTRUCTIONS.txt` — v2.0.0 is fully self-contained.

## 🐛 Known Issues

### Current Limitations

- Music playback requires FFmpeg installed on the host machine
- Leveling XP is per-server (no global XP across servers)
- Welcome images must be direct image URLs (no upload support)
- Giveaway maximum duration is 7 days
- Snipe only stores the last deleted message per channel

### Fixed from v1.0.0

- ✅ High-Low tie infinite loop resolved
- ✅ Math power operator now uses safe evaluation
- ✅ QuickChart API dependency removed (2048)
